# Can Suyu tanıtım sitesi

Can Suyu Android uygulamasını tanıtan statik web sitesi. Eski web uygulamasındaki hesap, Firebase, Drive ve oyun verisi kodları bulunmaz.

## Görünüm

Site altı ayrı ekrandan oluşur: Ana sayfa, Uygulama, Çiftlik, Mini oyunlar, İletişim ve İndir. Masaüstünde üst menü ve büyük hareketli sahneler, telefonda alt gezinme ve daha sıkı düzen kullanılır. Uygulama ekranında 20 saniyelik temsili sayaç, Çiftlik ekranında su verme animasyonu, Mini oyunlar ekranında üç çiftli hafıza denemesi vardır. Bu denemeler tarayıcıda veri kaydetmez. Çiftlik fotoğrafları doğal portre oranları korunarak gösterilir; galeriye basınca tam boy açılır.

## Yerel açma ve kontrol

- npm run dev komutunu çalıştırıp http://localhost:4173 adresini aç.
- npm run check ile JavaScript, dosya bağlantıları ve ekran yollarını denetle.
- İndirilen ZIP içindeki cansuyu-web klasörünün içeriklerini mevcut GitHub Pages deposunun köküne koy. CNAME alan adını içerir.
